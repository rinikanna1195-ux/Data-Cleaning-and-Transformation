# Data Cleaning and Transformation using Microsoft Excel

## 📌 Project Overview
This project focuses on cleaning, organizing, and transforming raw datasets using Microsoft Excel. The objective is to improve data quality and prepare datasets for further analysis.

## 📊 Workbook Description
The Excel workbook contains three worksheets:
- Raw_Dataset
- Working_Dataset
- Cleaned_Dataset

## 📝 Tasks Performed
1. Handling Missing Values
2. Correcting Inconsistent Data
3. Removing Duplicate Records
4. Splitting and Merging Columns
5. Number and Date Formatting
6. Applying Conditional Formatting

## 🛠️ Tools and Techniques
- Microsoft Excel
- Find and Replace
- Remove Duplicates
- Text to Columns
- Conditional Formatting
- Data Formatting

## 🎯 Learning Outcomes
- Understanding data cleaning techniques
- Handling missing and duplicate values
- Improving data consistency
- Transforming raw data into structured data
- Preparing datasets for analysis

## 📁 Project Deliverables
- Excel Workbook (.xlsx)
- Raw Dataset
- Working Dataset
- Cleaned Dataset

## 📌 Conclusion
This project provided practical experience in data cleaning and transformation using Microsoft Excel. It helped develop essential skills required for data preprocessing and data analysis.
